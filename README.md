# .me  
The Namespace Resolution Protocol (NRP) v0.1 defines a decentralized method for resolving me:// URIs across a distributed mesh, separating topological location from semantic resolution without central servers [1]. By utilizing cryptographic surface identities and a locally synced index, the protocol enables secure, offline communication and autonomous namespace ownership.
